# 核对结果

## 1. 四项核对（每次运行后，写进日志再下结论）

| 核对项 | 含义 |
| :--- | :--- |
| 规模 | 变量数、数据量与设计一致 |
| 约束或规则规模 | 约束行数、规则条数与设计一致 |
| 执行状态 | 正常完成，没有静默降级 |
| 结果数值 | 目标值、关键数值在合理范围 |

- 不适用的项写"不适用"，不省略
- 阶段结论写进 PLAN「步骤」的验证结果列

## 2. 基准（改已有代码前先建）

- 用当前代码跑出基准并保存到文件：逐时段数据、汇总指标、逐文件 md5
- 比对口径（列集、精度、判据、atol）事先写明；比对失败后不临时放宽

## 3. 判据（事先声明用哪一级）

- **逐位一致**：文件 md5 相同。前提：环境和库版本相同、线程数固定、随机种子固定、求解器结果确定、浮点输出格式固定。前提做不到时上报，经用户同意并记进 DECISIONS.md 后改用容差一致
- **容差一致**：下面两项都过才算过
  - 逐元素：`|新−基准| ≤ atol + rtol×|基准|`，rtol 默认 1e-4，atol 按单位在比对口径里写明
  - 总量：相对偏差 ≤ 1e-6；基准接近 0 时改用绝对偏差
- 一项过一项不过，算不一致，上报，不自行决定
- 在判据边界上浮动的结果上报，不四舍五入凑过

## 4. 数值安全

- 0/0、Inf−Inf 这类不定式显式处理；读取时的拦截见 `handle-input-data`
