# 类编写规则

边界：只管类的结构与注释。何时该封装成类归 `code-function`，
函数 docstring 格式归 `code-function`，数据缺值校验归 `algo-data`。

## 1. 通用类规则

- 一实体（一业务对象/一电源/一机组）一类，自包含；
  相关输入与变量作为实例属性，不散落在类外。
- 类 docstring 必写：一句话说清这个类**是什么**、装什么。
- 类型注解强制。

## 2. 数据类（@dataclass）规则

- 字段名英文；行尾必须有中文注释，写**语义 + 单位**，
  不写"它被谁用"。
- 字段多或跨主题 → 按主题拆子 dataclass，父类只做组合，
  每个字段注释其主题。
- 不需要分类的模块内数据类允许扁平（按实体整体聚合）；
  **不按"用途"拆数据类**——同组数据往往横跨多处使用，
  按用途拆会强迫调用方拼装。

## 3. 固定规则

- 对外暴露的键名/属性名是固定不变的对外约定，冻结；
  改名须升级而非覆盖。
- 生命周期方法顺序固定，顺序变化 = 破坏比对口径。

## 示例

```python
@dataclass
class TimeAxis:
    """时间轴：调度步数、步长、整点时刻序列与去重日期表。"""
    T: int                  # 调度时段数
    Delta_t: float          # 单位步长（小时）
    Time: pd.DatetimeIndex  # 整点时刻序列
    Day: list               # 去重日期表
    Nday: int               # 天数
```
