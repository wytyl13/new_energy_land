# 类

## 1. 通用

- 一个实体（一个业务对象、一个电源、一台机组）一个类；相关输入和变量作为实例属性，不散在类外
- 类 docstring 一句话说清这个类是什么、装什么

## 2. 数据类（@dataclass）

- 字段名英文；行尾写中文注释，内容是含义 + 单位，不写"被谁用"
- 字段多或跨主题时，按主题拆成子数据类，父类只做组合，每个字段注释其主题
- 不需要分类的模块内数据类可以扁平
- 不按"用途"拆数据类：同一组数据往往被多处使用，按用途拆会让调用方自己拼装
- 生命周期方法的调用顺序固定，顺序变了会影响结果比对

## 示例

```python
@dataclass
class TimeAxis:
    """时间轴：调度步数、步长、整点时刻序列与去重日期表。"""
    T: int                  # 调度时段数
    Delta_t: float          # 单位步长（小时）
    Time: pd.DatetimeIndex  # 整点时刻序列
    Day: list               # 去重日期表
    Nday: int               # 天数
```
