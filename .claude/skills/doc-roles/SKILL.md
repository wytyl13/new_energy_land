# 文档分工与修改权限

边界：只管三处文档的内容归属与修改权限。DESIGN.md 章节结构归 `design-doc`，
README 结构归 `readme-structure`，表述用词归 `style-wording`。

## 1. 三处文档装什么

| 位置 | 装什么 | 性质 |
|---|---|---|
| `.claude/skills/` | 通用规则，跨项目复用 | 通用 |
| `CLAUDE.md` | ①文档分工与更新规则 ②环境约定 | 通用 |
| | ③项目事实与当前进度 | 项目独有 |
| `DESIGN.md` | 本项目的设计、规划、进度、决策 | 项目独有 |

## 2. 修改权限（红线）

**非用户明示不可改：**
- skills 里已有规则的内容
- CLAUDE.md 的文档分工、更新规则、环境约定三段

**AI 可随进度更新（改完汇报）：**
- CLAUDE.md 的"项目事实与当前进度"段（进度从 DESIGN.md §6 摘要）
- DESIGN.md §6 进度表、§7 决策记录（只增）

**每次均须用户批准：**
- 新增 skill、修订 skill 内容
- CLAUDE.md 新增段落或指针

**带留痕的可改：**
- DESIGN.md §1–§5 冻结区：先在 §7 记决策，再改正文

## 3. 用户明示要求改"不可改"区时

- 可以改，但必须在 DESIGN.md §7 留痕：日期 / 改了什么 / 用户原话依据。
