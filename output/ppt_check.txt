（一）海陆划分的数据基础：格点地市归属表的生成与海陆标注
归属表由两个公开数据源自动生成——ERA5 海陆掩膜回答“是陆是海”，DataV 行政边界回答“属于哪个地市”，按格点坐标对齐合成一张表；一次生成，服务运行时只读。
01  两个输入
• 全国网格海陆分类.csv（ARCO-ERA5 land_sea_mask） / • 0.25° 网格全图 36685 点（18–54°N、73–136°E） / • 每点 0=陆 / 1=海：lsm>0.5 判陆，内陆湖点计海 / • DataV 行政区划边界 GeoJSON：省、市两级多边形
02  生成过程
• 格点中心 × 地市边界，做 point-in-polygon 判定 / • 落在某市多边形内才归属该市，只写 inside 行 / • 境外点、未命中点不指派（不写最近邻） / • 海陆判定按同一坐标键随行透传
03  产出
• 全国格点地市归属.csv（一次生成，运行时只读） / • 15440 点 × 370 地市单元 × 33 省（澳门无格点） / • 每行 = 坐标 + 省市 + 归属方式 + 海陆判定 / • 海南示例：海口 4 陆｜儋州 4 陆 + 1 海｜三沙 1 海
ERA5 海陆掩膜 / 全国网格海陆分类.csv（36685 点）
DataV 行政边界 / 省、市两级多边形（GeoJSON）
坐标对齐 + 多边形判定 / inside 归属 · 海陆列随行透传
全国格点地市归属表 / 15440 点 × 370 地市 × 33 省（含海陆判定列）
注：生成时质量校验（网格行数、海陆列无缺值、海点被归属 ≤1% 容差）不合格即报错不写盘；行政归属与海陆判定相互独立，同一市可陆海并存。

（二）程序适配①：取数拆分——陆风按市、海风成组
风电读取格点数据时按海陆判定拆成两条取数路径：陆格点按市聚合成陆风，请求范围内全部海格点合并为单一区域海风单元 sea；两类序列分别送入风电物理模型。
01  陆风
• 按市分组，各市只聚合自己的陆格点 / • 产出各市城市级风速序列 / • 口径与拆分前一致，仅剔除海点
02  海风
• 请求单元的海格点不分市 / • 全部海格点取并集，聚合为一组 / • 产出区域海风风速序列（sea 单元）
03  纯海单元
• 无陆格点的单元（如三沙、舟山） / • 跳过陆风计算并输出告警 / • 其海格点仍并入海组，格点不丢
请求计算单元 / （地市列表）
陆格点：按市分组 → N 组城市风速（陆风）
海格点：取并集 → 1 组区域海风风速（sea）
风电物理模型 / （算法零改动）
注：光伏不做海陆拆分，仍按单元聚合全部格点；拆分只发生在取数层，场景生成与物理模型算法零改动。

（三）程序适配②：请求、计算与输出的海风贯通
海风作为一个独立计算单元贯穿请求校验、并行计算与结果输出；对模型而言，sea 与普通城市单元无差别。
01  请求适配
• 新增平级键 sea_configs：region="sea"、capacity_mw、turbines / • 单元含海格点必传——防海风出力静默丢失 / • 无海格点传了报错 / • 与 city_configs 都缺省时，填服务端默认海风配置 / • （20 MW、6MW 机组、切变指数 0.70）
02  计算适配
• sea 作为独立任务键，与各市并列进同一并行池 / • 温度、气压数据与陆风同组读取 / • 汇总时海风装机计入总装机，出力计入省级出力
03  输出适配
• 出力表自动增列 sea_power_mw（城市列之后、末位） / • 返回 cities 含 "sea"，总装机含海风装机 / • 文件名 onshore_wind_power_ → wind_power_ / • 无海请求输出完全不变
对算法而言 sea 只是一个普通单元键 —— 请求、取数、并行、汇总均在业务层完成，算法包零改动
注：以上均为业务层适配；有海请求才增列、改名，纯陆请求输出与此前完全一致。
