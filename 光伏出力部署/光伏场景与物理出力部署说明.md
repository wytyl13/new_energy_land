# 海南光伏场景与物理出力部署说明

## 1. 功能概述

程序根据各地市的 8760 小时辐照度场景、地面温度和地面气压，依次完成水平面辐照度分解、组件倾斜面辐照度计算、组件温度估算和光伏出力计算。程序支持一个区域包含多个地市，以及每个地市配置多种组件，最后按小时汇总区域总出力。

## 1. 必要文件

- `generate_danzhou_solar_scenarios_city_specific.py`：儋州市三类辐照度场景生成程序。
- `generate_danzhou_pv_power_physical_model.py`：多地市、多组件辐照度到光伏出力的物理模型主程序。
- `run_danzhou_pv_scenario_and_power.py`：部署入口，直接运行即可生成出力场景。
- `danzhou_pv_physical_model_config.json`：城市装机、组件类型和物理参数配置。

部署时应保持上述文件在同一程序目录下；输入数据目录可以通过配置文件中的路径指定。

## 2. 外部输入

- 三类辐照度场景目录：每个资源年目录下提供 `01_地市名称8760辐照度场景.csv`，必须包含 `生成辐照度_W_m2` 列。
- `hainan_era5_grid_csv/temperature/`：温度格点 CSV，列名格式为 `temperature_2m_k_lat_纬度_lon_经度`。
- `hainan_era5_grid_csv/pressure/`：气压格点 CSV，列名格式为 `surface_pressure_pa_lat_纬度_lon_经度`。
- `海南地市分区/海南共同80格点_地市归属.csv`：用于严格边界格点筛选。

温度和气压程序会自动读取对应地市严格边界内的格点，转为北京时间，并对 2000--2024 年历史数据逐小时平均，作为物理模型输入。闰年会删除 2 月 29 日，统一为 8760 小时。

## 3. 配置项

- `loss_factor`：汇集、逆变及线路等综合损耗系数。
- `cities`：地市列表，键名建议采用 `行政区代码_地市名称`。
- `scenario_dir`：该地市三类辐照度场景所在目录。
- `capacity_mw`：该地市光伏装机容量。
- `latitude`、`longitude`：该地市代表性经纬度，用于太阳位置和倾斜面辐照度计算。
- `components`：地市内部的组件列表。
- `capacity_share`：组件容量占该地市装机容量的比例，所有组件比例之和应为 1。
- `tilt_deg`、`azimuth_deg`：组件倾角和方位角。
- `noct_c`：组件额定工作温度。
- `gamma_p_per_c`：功率温度系数。
- `efficiency`：组件或设备效率系数。
- 增加地市或组件类型只需在 JSON 中新增对应配置，主程序会逐地市计算并生成区域汇总，不需要修改主程序。

示例结构：

```json
{
  "loss_factor": 0.90,
  "albedo": 0.20,
  "cities": {
    "460400_儋州市": {
      "capacity_mw": 955.21,
      "latitude": 19.56,
      "longitude": 109.58,
      "scenario_dir": "海南儋州市三类辐照度场景...",
      "components": [
        {
          "name": "常规组件",
          "capacity_share": 0.60,
          "tilt_deg": 18,
          "azimuth_deg": 180,
          "noct_c": 45,
          "gamma_p_per_c": -0.004,
          "efficiency": 1.0
        }
      ]
    }
  }
}
```

## 4. 输出内容

每个地市、每类资源年输出一个 8760 小时 CSV，包含：生成辐照度、地面温度、地面气压、各类组件 POA 辐照度、组件温度、组件出力、地市总出力 MW 和标幺值。

区域汇总文件额外包含各地市总出力、区域总出力 MW 和区域总出力标幺值；摘要文件包含平均出力、最大出力、年利用小时和容量因子。

输出目录：`海南区域光伏物理模型出力场景_多地市版`。

## 5. 运行方式

```powershell
$env:PYTHONNOUSERSITE='1'
python run_danzhou_pv_scenario_and_power.py
```

部署环境需要 `numpy`、`pandas`、`matplotlib`。程序按北京时间输出，闰年数据统一为 8760 小时。

## 6. 运行检查

运行后应检查：

1. 每个地市三类场景是否均生成 8760 行数据；
2. 各组件 `capacity_share` 之和是否为 1；
3. 出力是否非负且不超过配置装机容量的合理范围；
4. 区域总出力是否等于各地市出力逐小时相加；
5. 温度、气压和辐照度时间轴是否均为北京时间。
