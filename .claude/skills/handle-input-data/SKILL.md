# 处理输入数据

红线（缺值立即报错、禁止补 0）见 CLAUDE.md「数值与公式红线」，这里写怎么落实。

## 1. 输入归属

- 多个模块都用的公共输入：在输入层统一读取
- 只有一个模块用的输入：在该模块内读取，不放进公共输入层
- 同一份数据只读一次、只存一份，不在各模块重复读

## 2. 校验位置

- 读取时在入口校验一次，不在计算中途散布检查

## 3. 校验内容

- 行列完整、时间轴对齐、取值范围（如负的容量）、类型和单位

## 4. 报错格式

- 指明哪个表、哪一列或哪条记录、缺什么或错什么
