# DESIGN.md 写法

DESIGN 只有两部分：算法设计、工程实现。DESIGN 先于代码。拿不准的内容不写。
算法设计的完整范例见 examples/algo-design.md。

## 算法设计

依次四节：背景、流程图、维度流转、模块对应。
流程图、维度流转、模块对应三处的阶段编号和名称完全一致。

### 背景

- 一段话写清：问题、输入、方法、输出、原则
- 末尾列出用到的 `docs/ref/` 原始资料路径

### 流程图

- 标题：`<项目>·数据流转网络图`
- 列是阶段，最左为输入，最右为输出；行是并行分支
- 节点用圆形，标"分支 + 操作"；同一列同一颜色；连线表示数据流向
- 每列底部三行：阶段编号 + 名称、输出形状、关键规则（分支之间用 `|` 隔开）
- 输出列按组展开
- 最下一行列出不变量
- 画图：复制 scripts/make_flowchart.py，只改数据部分（标题、节点、连线、列标注、不变量），运行出 PNG；样式对照 examples/flowchart.png

### 维度流转

- 输入一行一个：名称、形状、类型、单位、含义；各维度的含义写在该行注释里（如 `76=年份数`）
- 阶段标题写：编号、名称、范围（各分支共用，或属于某个分支）
- 每行一个操作：操作 → 形状 → 说明
- 每次形状变化标明类型：归约（沿哪个维度、怎么归约）、新增维度（来源）、变化（依据）、不变（变的是什么）
- 输出的各维度逐个拆开说明
- 列出不变量

### 模块对应

- 粒度到文件
- 重构项目写两列：原项目模块、新项目模块；新项目只写新项目模块一列

## 工程实现

按理论对象拆，不按步骤拆。依次：

1. 对象分类表：类型 → 对象列表
2. 逐个对象写：描述、变量、结构、规则、输入、输出
   - 规则项写公式，注明 `docs/ref/` 出处（写法见 `write-math-formula`）
   - 配置参数的默认值登记在变量项
3. 跨对象：对象之间的关系和全局约束
4. 输入汇总
5. 输出汇总
