# 文档同步

代码改了文档没同步，改动未完成。

## 改了什么 → 同步哪里

| 改动 | 同步 |
| :--- | :--- |
| 接口的传参或返回 | API.md；测试里的格式断言 |
| 输出文件的列集、行序、精度 | 先在 DECISIONS.md 记一条，再改 DESIGN「输出汇总」 |
| 算法阶段、形状变化 | DESIGN「流程图」「维度流转」「模块对应」三处一起改 |
| 新增、删除、改名模块文件 | DESIGN「模块对应」 |
| 配置参数或默认值 | DESIGN 对应对象的变量项，或 API.md |
| 运行命令、环境、依赖 | README「Quick Start」 |
| 步骤完成、验证结果 | PLAN「步骤」 |

- 描述冲突时以代码为准，同步改其他地方，不只改一处
- 改前查表，改完逐行核对

## 引用

- 正文引用代码统一写 `[n]`，链接只指到文件，不写行号；函数名写在正文里
- 编号只增，不复用；每个文档在文末维护自己的映射表
- 映射表按对象分组注释（如 `<!-- 某对象 xxx.py -->`）

## 格式

- 沿用文档原有格式（表格对齐、章节顺序、标点），不顺手美化
- 大改分小步：先改表格行，再补链接，最后检查链接能跳转
