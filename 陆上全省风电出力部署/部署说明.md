## 主要计算过程

各地市生成风速先按风切变指数修正到轮毂高度，再进行轮毂高度温度和气压修正，计算空气密度，最后按切入、额定和切出风速对应的分段功率曲线计算机组出力。各地市出力按照配置文件中的装机权重汇总为全省出力。

## 配置内容

- `scenario.year`：输出年份；
- `scenario.resource_year_type`：偏小、正常或偏大资源年；
- `loss_factor`：综合损耗系数；
- `city_configs`：必填的地市级多机型配置；每个地市填写 `capacity_mw` 和 `turbines`，每个机组填写台数、额定功率、轮毂高度、切入/额定/切出风速和效率；
- `output_dir`：出力结果目录。

全省装机容量由 `city_configs` 中所有地市的 `capacity_mw` 自动求和，不再单独填写全省装机容量或地市权重。

## 地市多机型配置

需要每个地市分别配置多种机组时，参考 `city_turbine_configs.example.json`，将其中的 `city_configs` 合并到主配置文件。每个地市的配置形式为：

```json
"460400_儋州市": {
  "capacity_mw": 37.15,
  "turbines": [
    {
      "model": "6MW机组",
      "count": 4,
      "rated_power_mw": 6.0,
      "hub_height_m": 140.0,
      "cut_in_m_s": 3.0,
      "rated_m_s": 11.0,
      "cut_out_m_s": 25.0,
      "efficiency": 0.94,
      "wind_shear_exponent": 0.15
    }
  ]
}
```

如果同一地市有 2 MW、6 MW、12 MW 三种机组，就在 `turbines` 数组中填写三条记录。程序会先按台数和额定功率计算配置容量，再按 `capacity_mw` 对机组出力进行统一缩放，确保该地市出力与实际装机容量口径一致。结果文件中会同时保留各地市出力列。
