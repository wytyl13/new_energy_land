# 写数学公式

## 1. 只在被要求时写

- 用户没明确要求，不在注释、文档、代码里写公式；代码用直白的变量名和注释说明逻辑

## 2. 出处

- 每个公式、约束、目标项都要能在 `docs/ref/` 找到出处，不凭直觉补文档没写的项
- 公式写在 DESIGN「工程实现」对应对象的"规则"项，注明出处（文件、章节、式号）
- 代码实现处注释同样标出处
- 文档和代码冲突时写进 PLAN「待决定」

## 3. 变量与单位

- 变量名和文档符号对应，对应关系写注释
- 每个物理量带单位，写在注释和数据类字段注释里；混合单位（kW/MW、h/min）显式换算

## 4. 求和与表达式

- 写清求和范围、下标含义、时刻对齐方式（前闭后开、端点处理）
- 目标函数各分项的相加顺序固定（影响浮点结果和比对）
- 中间量按物理含义命名，不用 `tmp1`、`aux2`
- 同一公式只有一个实现，多处使用时复用同一函数
