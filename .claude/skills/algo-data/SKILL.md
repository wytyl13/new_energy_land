# 输入数据规则

边界：只管输入数据怎么读、怎么校验。数据类结构形态归 `code-class`，
公式对照归 `algo-modeling`。

## 1. 数值严谨（红线）

- 缺列、缺值、缺记录 → **立即报错报告**，禁止：
  - 补 0、补默认值；
  - 插值、前向填充；
  - 静默跳过该行/该时刻。
- 报告要指明：哪个表、哪列/哪条记录、缺什么。
- NaN/Inf 不进模型与计算；不确定的数值显式处理并注明依据。

## 2. 输入归属

- 系统公共输入（多个模块都用）→ 集中在输入层统一读取。
- 模块专属输入 → 在对应模块内读取，不塞进公共输入层。
- 同一份数据只读一次、只存一份，禁止各模块各自重复读。

## 3. 校验位置

- 校验发生在**读取时**（入口处一次），不在计算中途散布检查。
- 校验内容：行列完整性、时间轴对齐、取值范围（如负的容量）、
  类型与单位。
