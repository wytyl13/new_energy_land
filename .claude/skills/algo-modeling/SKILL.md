# 数学公式编写规则

边界：只管"公式怎么写、怎么对照文档"。输入数据缺值校验归
`algo-data`，数值容差归 `process-verify`。

## 1. 先决条件：仅在被要求时写

- **默认不在注释、文档、代码里写数学公式**；
  仅当用户明确要求"写公式 / 推导 / 建模"时才写。
- 用户没要求时，代码用直白的变量名和注释说明逻辑即可，
  不主动补公式。

## 2. 公式对照（写公式时的红线）

- 每个公式、约束、目标项必须能在理论/规格文档中找到出处；
  **禁止自创公式、禁止凭直觉补文档没写的项**。
- 文档与代码公式冲突时上报裁决（见 `process-workflow` 权威顺序），
  不自行决定。
- 公式实现处注释标明文档出处（章节/式号），方便回溯。

## 3. 变量与单位

- 变量命名与文档符号保持可追溯的对应；对应关系写注释。
- 每个物理量带单位，单位写在注释与数据类字段注释里；
  混合单位（kW/MW、h/min）必须显式换算，不隐式约定。

## 4. 符号与求和规则

- 求和范围、下标含义、时刻对齐方式（前闭后开、端点处理）
  显式写清；这类细节是错数的主要来源。
- 目标函数 = Σ各分项，**加法顺序冻结**（影响浮点结果与比对）。

## 5. 表达式规则

- 中间量命名说物理含义，不写 `tmp1/aux2`。
- 一处公式一个实现，多处使用复用同一函数（见 `code-function`）。
